## 2. Images — overview

The design uses **several distinct photo roles**. You do not need 16 totally different shoots if some images can double up (e.g. one strong food shot used in more than one place), but each **role** below should either get a dedicated file or you tell us which file to reuse where.

**Technical preferences (helps the site look sharp):**

- **Hero / banner images:** landscape, high resolution (roughly **2000px+** on the long edge if possible).
- **Portrait:** vertical or crop-friendly; face / upper body works well for the tall panels.
- **Gallery / produce grids:** mix of landscape and portrait is fine; we crop to the layout.
